# 나만의 텍스트 편집기

복잡한 검색식이나 정규식을 외우지 않고도 원하는 줄을 찾고, 추출하고, 정리할 수 있는 Windows용 텍스트 편집기입니다.

## 주요 기능

- 여러 문서를 탭으로 열어 편집하고 저장
- Scintilla 기반 대용량 로그 편집과 파일·다중 파일 드래그 앤 드롭
- `모두 포함`·`하나라도 포함`·`제외` 입력과 삭제 가능한 조건 태그
- 검색할 때마다 독립적으로 남는 결과 탭과 원문 스냅샷
- 선택·전체 결과 복사(줄 번호 선택), 새 문서 추출, 삭제 미리보기
- 원문 수정·닫힘 뒤에도 유지되는 검색 결과 복사
- 기준 텍스트 앞쪽·뒤쪽·사이 삭제 및 두 기준 사이만 남기기
- Unicode 글자 단위 좌우 삭제, 접두·접미 추가, 구분자 분할·줄 합치기
- 줄 번호 추가와 편집기에서 붙인 줄 번호 제거
- 중복 줄, 빈 줄, 연속 빈 줄, 줄 앞뒤 공백 정리
- 모든 텍스트 정리의 미리보기와 확인창 없는 바로 적용
- 문자열 일괄 치환과 특정 문장을 포함한 줄 전체 삭제
- ANSI 코드·C0/DEL 제어문자·줄 끝 공백·연속 빈 줄을 제거하는 보수적 로그 정리
- 상단에 직접 고정하는 텍스트 도구 즐겨찾기
- 검색 조건과 옵션을 복원하는 최근 검색 20개
- 완성된 라이트·다크 테마, 한글 표시 글꼴 목록과 작업 UI 자동 저장
- UTF-8·UTF-16·Windows 한국어 인코딩과 CRLF·LF 보존

## 개발 환경

- Windows 10/11 x64
- .NET SDK 9.0 이상

## 빌드 및 실행

```powershell
dotnet build MyTextEditor.sln -c Release
dotnet run --project src/MyTextEditor/MyTextEditor.csproj
```

## 테스트

```powershell
dotnet run --project tests/MyTextEditor.Core.Tests/MyTextEditor.Core.Tests.csproj -c Release
dotnet run --project tests/MyTextEditor.Performance/MyTextEditor.Performance.csproj -c Release
```

테스트 프로젝트는 외부 테스트 프레임워크 없이 실행 가능한 자체 검증 프로그램입니다. 실패한 검증이 있으면 0이 아닌 종료 코드로 끝납니다.
성능 실행기는 3천만 자 UTF-8 로그를 세 번 열고 Scintilla 렌더까지 잰 중앙값이 2초를 넘으면 실패합니다.

## 검색 결과 탭

찾기를 실행할 때마다 하단에 새 결과 탭이 생깁니다. 여러 탭은 같은 원문의 같은 시점에서 생성됐다면 원문 스냅샷을 공유합니다. 결과 행을 여러 개 선택해 `Ctrl+C`로 복사할 수 있고, 도구 모음에서 선택/전체 복사와 줄 번호 포함 여부, 선택/전체 추출·삭제 미리보기를 고를 수 있습니다. 원문을 수정하거나 닫아도 결과와 복사는 유지되며, 원문에 영향을 주는 동작만 비활성화됩니다.

탐색기에서 파일 하나 또는 여러 파일을 창이나 편집 영역으로 끌어 놓아 열 수 있습니다. 이미 열린 파일은 기존 탭으로 이동하고 폴더는 제외합니다.

## 검색 조건 예시

`AAA`와 `BBB`가 모두 포함되고 `CC`가 없는 줄을 찾으려면 다음처럼 입력합니다.

- 모두 포함: `AAA, BBB`
- 제외: `CC`

쉼표로 검색어를 나누면 아래에 조건 태그가 표시되고 `×`로 하나씩 삭제할 수 있습니다. Enter를 누르면 바로 검색합니다.

`하나라도 포함`에는 OR로 찾을 단어를 쉼표로 입력합니다. `최근 검색`에서는 세 조건과 대소문자, 완전한 단어, 문맥 옵션을 한 번에 복원할 수 있습니다. 같은 검색은 하나만 유지되고 최근 20개까지 저장됩니다.

## 유용한 기능 예시

- 머리 자르기: `앞부분AAA내용` → `AAA내용`
- 꼬리 자르기: `내용BBB뒷부분` → `내용BBB`
- 사이 지우기: `앞AAA삭제할내용BBB뒤` → `앞AAABBB뒤`
- 사이만 남기기: `앞AAA남길내용BBB뒤` → `AAA남길내용BBB`
- 좌우 글자 삭제: 한글과 이모지 같은 Unicode 문자를 중간에서 자르지 않고 N글자 제거
- 접두·접미: 각 줄 앞이나 뒤에 지정 텍스트 추가, 빈 줄 포함 여부 선택
- 구분자 분할·줄 합치기: 빈 항목과 공백을 보존해 여러 줄로 나누거나 한 줄로 합치기
- 줄 번호: 시작 번호와 구분자를 지정해 추가하거나 같은 형식을 제거
- 특정 문장 포함 줄 삭제: 입력한 문장이 들어간 줄 전체를 미리보기 후 삭제
- 로그 정리: ANSI 터미널 코드, NUL과 탭·개행을 제외한 C0/DEL 제어문자, 줄 끝 공백을 제거하고 연속 빈 줄을 하나로 축소

기준 텍스트 유지 여부를 선택할 수 있으며, 기준을 찾지 못한 줄은 변경하지 않습니다. 각 기능은 결과를 미리보거나 확인창 없이 바로 적용할 수 있습니다. 변경이 없으면 적용하지 않으며, `Ctrl+Z` 한 번으로 되돌릴 수 있습니다. `특정 문장 포함 줄 삭제`는 일치한 행의 줄바꿈까지 제거하되 원본 파일의 끝 개행은 유지합니다.

## 글꼴과 화면

상단 `글꼴` 입력에서 Windows에 설치된 글꼴을 검색할 수 있습니다. 맑은 고딕, D2Coding, 나눔고딕, Noto Sans KR, Pretendard, Cascadia Mono, Consolas, JetBrains Mono와 기본 한글 글꼴은 설치되어 있으면 목록 위쪽에 표시됩니다. 저장한 글꼴이 삭제된 경우 맑은 고딕이나 Consolas로 안전하게 대체합니다. 좁은 창에서는 글꼴과 크기 설정이 상단 오버플로 버튼으로 이동합니다.

상단 `☆ 편집`에서 자주 쓰는 정리 기능을 선택하면 즐겨찾기 버튼으로 고정됩니다. 입력이 필요한 기능은 해당 입력칸으로 이동하고, 중복 줄 제거 같은 즉시 실행 기능은 바로 변경 미리보기를 엽니다.

테마, 글꼴, 창과 패널 상태, 검색 조건, 도구 입력값, 즐겨찾기와 최근 검색은 변경 후 자동 저장되어 다음 실행에서 복원됩니다. 문서 내용과 검색 결과 탭은 자동 복원하지 않습니다.

## 기본 단축키

| 동작 | 단축키 |
| --- | --- |
| 새 문서 | `Ctrl+N` |
| 파일 열기 | `Ctrl+O` |
| 저장 | `Ctrl+S` |
| 다른 이름으로 저장 | `Ctrl+Shift+S` |
| 찾기 패널 | `Ctrl+F` |
| 바꾸기 | `Ctrl+H` |
| 현재 탭 닫기 | `Ctrl+W` 또는 `Ctrl+F4` |
| 모든 탭 닫기 | `Ctrl+Shift+W` |
| 다음·이전 탭 | `Ctrl+Tab`·`Ctrl+Shift+Tab` 또는 `Ctrl+PageDown`·`Ctrl+PageUp` |
| 다음·이전 검색 결과 | `F3`·`Shift+F3` |
| 실행 취소 | `Ctrl+Z` |
| 다시 실행 | `Ctrl+Y` |

## 배포

```powershell
dotnet publish src/MyTextEditor/MyTextEditor.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o artifacts/win-x64
```

`artifacts/win-x64` 폴더를 압축하면 .NET 설치 없이 실행 가능한 배포본을 만들 수 있습니다.

# v1.11.17 배포 확인

완료한 동작 테스트를 반복하지 않고 구현 단계의 결과를 재사용했다.

- 폴더 비교 응답성·Core 검증: [폴더 비교 검증 기록](../folder-compare-lazy-2026-11-11.md).
- `--folder-input`: 경로 Enter, 따옴표 경로, 좌우 및 두 폴더 드롭, 파일/폴더 혼합 거절, 기존 파일 버퍼 보존, 파일 입력·오류 회귀 통과.
- `--folder-compare`: 자식·손자 폴더 새 탭, 상위 탭 복귀 및 선택 유지, 상위 탭 종료 후 하위 탭 독립성, 한쪽 전용 항목 저장·갱신과 기존 파일 비교 회귀 통과.
- 최종 구현 Release 빌드 경고 0개·오류 0개.

배포 단계에서는 버전만 1.11.17로 갱신하고 Windows x64 자체 포함 단일 EXE를 패키징했다. EXE 파일 버전은 1.11.17.0이며 ZIP 안의 EXE SHA-256은 원본 EXE와 일치한다. `package.json`에 크기·해시를 기록했다. 최종 단일 EXE를 별도로 실행하거나 GUI 테스트를 반복하지 않았다.

사용자 `.gitignore` 변경은 커밋에서 제외했다. 기존 실행 중인 사용자 창을 종료하지 않았다. GitHub 공개 상태와 서버 첨부 파일 무결성 확인 결과는 `publication.json`에 기록한다.

# OmniEdit v1.11.17

## 개선 사항

- 폴더를 비교 창의 좌우 영역이나 경로 입력란에 드래그하거나, 폴더 경로를 입력한 뒤 Enter를 눌러 폴더 비교를 시작할 수 있습니다. 두 폴더 동시 드롭과 따옴표로 감싼 경로도 지원합니다. 한쪽만 지정하면 다른 쪽 입력을 기다립니다.
- 파일·폴더 비교에 좌우 공통 경로 입력줄을 제공합니다. 기존 파일 비교 내용이 있으면 그 탭을 유지하고 폴더 비교를 새 탭으로 엽니다.
- 하위 폴더를 더블클릭하거나 Enter로 열면 새 폴더 비교 탭이 생성됩니다. 원래 탭의 경로·목록·선택·스크롤은 유지되며, `↑ 상위 탭`으로 원래 탭에 돌아갈 수 있습니다. 상위 탭을 닫아도 하위 탭은 유지됩니다.
- 현재 폴더 바로 아래 항목만 비교하고 하위 폴더는 열 때 비교합니다. 대량 항목을 목록에 표시하는 처리와 파일 비교 버퍼 사용을 개선해 UI 지연과 메모리 할당을 줄였습니다.
- 한쪽에만 있는 폴더도 새 탭에서 비교할 수 있으며, 대응 파일을 저장하기 전에는 반대쪽 폴더를 만들지 않습니다. 전체 갱신은 F5입니다.

## 사용 방법

- Windows x64 자체 포함 EXE입니다. .NET 설치 없이 EXE를 실행하거나 ZIP을 풀어 사용하세요.
- 기존 메인·비교/병합 창을 모두 종료한 뒤 실행 파일을 교체하세요. 설정·매크로 저장 경로는 기존 `%LOCALAPPDATA%\MyTextEditor`를 유지합니다.

## 검증

- 구현 단계의 Release 빌드 0경고/0오류, Core 44/44, 대량 폴더 비교, 경로 Enter·좌우 드롭·동시 드롭·파일 비교 회귀, 자식·손자 새 탭·상위 복귀·탭 독립성 검증 결과를 재사용합니다.
- 이번 배포에서는 완료한 동작 검증을 반복하지 않고 자체 포함 EXE·ZIP 패키징, 버전, ZIP 내부 실행 파일과 GitHub 첨부 파일의 크기·SHA-256 일치를 확인합니다.
- 실제 혼합 DPI 전환과 물리 한글 IME 조합 검증은 포함하지 않았습니다.

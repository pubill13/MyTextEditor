최초 배포 검증에서 모든 실제 EXE 시나리오는 통과했으나, 정상 종료 직후 OS 프로세스 목록에 남은 종료된 항목을 실행 중으로 분류하여 설정 복원을 중단했습니다. 테스트는 설정 원본을 보존했습니다.

실행 중인 OmniEdit이 없음을 확인한 뒤 원본을 복원하고, 테스트 정리 검사를 Process.HasExited 기준으로 수정했습니다. 빌드와 실제 EXE instance199를 다시 실행해 종료·취소·재접수 및 설정 복원까지 종료 코드0으로 통과했습니다.

PowerShell5에서 JSON 배열이 단일 pipeline 항목으로 취급되어 재실행 결과가 중첩된 기록 문제도 평탄화했습니다. 각 시나리오의 마지막 실제 실행 결과를 사용하며, 최초 실패 기록은 initial-validation-failure.json과 로컬 attempt1-instance199.log에 보존했습니다.

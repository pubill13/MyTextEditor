# OmniEdit v1.11.14

## 개선 사항
- 연결 프로그램으로 CSV·CFG 등 여러 파일을 빠르게 실행할 때 첫 창의 준비나 편집 작업 때문에 발생하던 접수 지연과 3초 오류를 개선했습니다. 추가 실행은 창·글꼴·편집기를 초기화하지 않고 파일 경로만 전달합니다.
- 요청 접수를 UI와 분리하고 보관한 뒤 차례로 엽니다. 프로세스의 접속 순서가 바뀌거나 앞선 실행이 늦게 도착해도 실행 순서대로 탭을 배치합니다. 이미 열린 파일은 기존 탭과 위치를 유지합니다.
- 저장 등으로 잠시 바쁜 창에는 접수한 요청을 보관했다가 이어서 엽니다. 창 종료·종료 취소·다른 창으로 수신을 이어가는 경로에서 요청 유실과 접수 정지를 방지했습니다.
- 일반 문서의 파일 변경 모니터링은 외부 변경을 불러오기 전에 확인합니다. 저장하지 않은 수정이 있으면 버려진다는 경고를 표시하며, 같은 변경을 거절하면 다시 묻지 않습니다. `파일 → 디스크에서 다시 불러오기`로 수동 재시도할 수 있습니다.
- 비교/병합에서도 연결된 원본이나 직접 연 파일의 새 변경을 확인하고, 승인 후 잠금을 유지한 채 다시 불러옵니다. 읽는 도중의 추가 편집·저장·소스 교체·종료와의 경합을 보호합니다.
- 비교/병합 옵션에 기본 OFF인 `가로 스크롤 동기화`를 추가했습니다. 세로 동기화와 독립적으로 설정·저장됩니다.
- 병합할 때 양쪽 화면 위치를 유지합니다. `병합 후 다음 차이`를 켠 경우에만 다음 차이로 이동합니다. 반복 재로드 후 편집 멈춤과 비동기 저장의 UI 스레드 오류를 수정했습니다.
- 편집 후 다시 검색한 결과의 클릭·키보드 이동이 최신 줄을 정확히 선택하도록 보완했습니다. 한글·이모지·빈 줄과 줄 끝 처리도 검증했습니다.
- 비교/병합 명령바의 `좌우 교환` 기능을 제거하고 도움말을 현재 화면에 맞췄습니다.

## 사용 방법
- Windows x64용 자체 포함 단일 EXE입니다. .NET을 별도로 설치할 필요가 없습니다.
- `OmniEdit.exe`를 내려받아 실행하거나 ZIP을 풀어 사용하세요.
- **업그레이드 전 기존 메인·비교/병합 창을 모두 종료한 다음 새 EXE로 교체하세요.** CSV·CFG 등의 연결 프로그램도 새 EXE 경로로 지정하세요. 파일 전달 프로토콜이 변경되어 이전 실행본과 새 실행본을 동시에 사용하는 것은 피해야 합니다.
- 사용자 설정·매크로·복구 저장소는 기존 `%LOCALAPPDATA%\MyTextEditor` 경로를 유지합니다.
- 마지막 창에서 종료 확인 중 새 파일을 열면 요청을 거절합니다. 종료 확인을 취소하거나 마친 뒤 다시 열어 주세요.

## 검증과 제약
- 실제 EXE의 50ms 간격 CSV/CFG cold 20개 + warm 20개 연속 실행, 정확한 탭 순서, 누락·중복·오류창 없음, 정상 종료를 검증했습니다.
- UI를 5초 멈춘 상태의 요청 접수·보존, 늦게 도착한 이전 실행의 순서, 마지막 창 종료 및 취소 후 재접수, 외부 변경 승인·거절·수동 재시도, 병합·검색·문서 분리 회귀를 검증했습니다.
- 대용량 단일 줄의 UI 지연 제약은 남아 있으며 실제 혼합 DPI 전환과 물리 한글 IME 조합은 이번 검증에 포함하지 않았습니다.

## 변경 사항

- 찾기 입력칸에서 Enter를 반복하면 다음 일치 항목으로 이동합니다. 문서 끝에서는 처음부터 이어서 찾으며 본문은 그대로 유지됩니다.
- 현재 문서, 열린 파일 전체, 폴더에서 검색 결과가 0개이면 확인 팝업을 표시합니다.
- 가운데 구분선을 드래그해 좌우 문서 영역의 너비를 조절할 수 있습니다. 문서 탭을 끌어 분할할 수 있는 영역도 넓혔습니다.
- 메인 창의 최소 너비를 1040 DIP에서 720 DIP로 낮췄습니다. 좁은 창에서는 상단 도구 모음을 두 줄로 표시합니다.

## 다운로드

Windows x64용 자체 포함 실행 파일입니다. OmniEdit.exe를 바로 실행하거나 ZIP을 풀어 실행하세요.

# OmniEdit v1.11.15

## 개선 사항

- 비교/병합 창을 일반 편집기와 독립된 창으로 변경했습니다. 선택한 창을 앞으로 가져오고 각 창을 따로 최소화·복원할 수 있습니다. 저장된 창 위치, 테마 적용, 메인 창 종료 후 비교/병합 작업 유지 기능은 보존합니다.
- 대응되는 줄의 정렬을 유지하면서 휠·세로 스크롤바·PageUp/Down 입력 중 반대편 위치를 즉시 동기화합니다. 반대편이 다음 화면 갱신 때 뒤늦게 따라오던 현상을 개선했습니다.
- 스크롤할 때 이전 화면에 그린 강조 범위만 갱신하여 대용량 문서의 표시 비용을 줄였습니다. 화면 밖 줄의 상세 비교 작업이 최신 화면 갱신을 방해하지 않도록 개선했습니다.
- 기존 설정·파일·파일 전달 프로토콜 형식은 유지합니다.

## 사용 방법

- Windows x64용 자체 포함 EXE입니다. .NET 별도 설치 없이 EXE를 실행하거나 ZIP을 풀어 사용하세요.
- 업그레이드 전 기존 메인·비교/병합 창을 모두 종료한 뒤 새 실행 파일로 교체하세요. CSV·CFG 등의 연결 프로그램 경로도 확인하세요.
- 사용자 설정·매크로·복구 저장소는 기존 `%LOCALAPPDATA%\MyTextEditor` 경로를 유지합니다.

## 검증

- 실제 클릭·Alt+Tab·독립 최소화·창 위치·테마·도움말·메인 종료 후 작업 유지 검증을 통과했습니다.
- 차이 4,210개 자료와 30/100/300MB 문서에서 좌우 휠·PageUp/Down·스크롤바 입력 2,880회를 측정했습니다. 입력 반환 시 동기화 지연은 수정 전 1,920건에서 0건으로 줄었고, 입력 처리 p95 최대 1.10ms였습니다. 비교 완료 상태에서 측정한 결과이며 모든 화면 그리기 시간이 16ms 이내임을 의미하지 않습니다.
- 추가·삭제 구간과 문서 시작·끝 매핑, 동기화 OFF, 가로 동기화, 병합 후 화면 위치, Undo/Redo, 편집·재로드 후 강조 초기화를 검증했습니다.
- 비교 계산과 화면 그리기 시간은 문서·PC 환경에 따라 달라집니다. 실제 혼합 DPI 전환과 물리 한글 IME 조합은 이번 검증에 포함하지 않았습니다.

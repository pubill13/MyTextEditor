## 변경 사항

- 문서 편집 중 Ctrl+Shift+W로 모든 탭을 닫을 때, 저장 여부를 물을 문서가 두 개 이상 남아 있으면 **모두 아니오**로 남은 변경 사항을 한 번에 버릴 수 있습니다. 파일 메뉴와 탭 우클릭 메뉴에서도 사용할 수 있습니다.
- 단어를 더블클릭하면 같은 단어에, 텍스트를 드래그하면 다른 단어 안의 같은 부분에도 음영을 표시합니다. 대소문자를 구분하며 선택을 해제하면 음영이 사라집니다.

## 다운로드

Windows x64용 자체 포함 실행 파일입니다. OmniEdit.exe를 바로 실행하거나 ZIP을 풀어 실행하세요.

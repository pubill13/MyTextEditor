# OmniEdit v1.11.19

## 개선 사항

- 비교 경로의 Enter 처리를 보강했습니다. 파일·폴더 비교 중 한쪽 경로를 바꿔도 현재 탭에서 다시 비교하며 반대쪽은 유지합니다. IME 조합 확정과 키 반복으로 비교 명령이 실행되지 않도록 처리했습니다.
- 좌우 경로 입력창에 최근 경로 `▾` 메뉴를 추가했습니다. 선택하면 해당 입력창만 채우며 Enter로 불러옵니다. 파일·폴더별 최근 30개를 저장하고 재시작 후에도 유지합니다.
- 경로 입력창 글꼴을 Segoe UI로 고정하고, 폴더 목록 열 제목에 정렬 방향 전환 안내를 추가했습니다. 이름·날짜·형식·크기·상태 정렬 시 좌우 대응 행을 유지합니다.
- 미저장 파일 소스 교체를 취소하면 기존 경로를 복원합니다. 기존 설정 파일과 호환됩니다.

## 검증 및 알려진 사항

- 구현 단계에서 Release 빌드 0경고/0오류, Core 44/44, 폴더 비교·경로 입력·최근 경로 회귀 테스트를 통과했습니다. 헤더 클릭 처리 경로를 통한 정렬, 양쪽 경로 Enter 후 탭 유지, 이력 중복·개수 제한·설정 저장/복원을 확인했습니다.
- 완료한 테스트는 이번 배포에서 반복하지 않습니다. Windows x64 자체 포함 EXE·ZIP의 버전 및 SHA-256과 GitHub 첨부 무결성을 확인합니다.
- 경로 입력창과 본문에서 영문이 넓게 입력되는 현상은 사용자 환경에서 `Alt + =`로 문자 폭 모드가 전환된 경우로 확인됐습니다. 같은 단축키로 정상 입력으로 돌아올 수 있으며, 앱 버그 수정 항목은 아닙니다. 실제 한글 IME와 여러 화면 배율에서의 개발자 수동 검증은 미수행했습니다.

## 설치

- Windows x64 자체 포함 실행 파일로 .NET 별도 설치가 필요 없습니다. `OmniEdit.exe`를 받거나 ZIP을 풀어 실행하세요.
- 실행 파일 교체 전 기존 메인 창과 비교·병합 창을 모두 종료하세요. 설정과 매크로는 기존 `%LOCALAPPDATA%\MyTextEditor`에 유지됩니다.

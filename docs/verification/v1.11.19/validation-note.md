# v1.11.19 배포 검증

현재 구현 단계에서 완료한 Release 빌드(0경고/0오류), Core 44/44, `--folder-input`, `--folder-compare` 검증 결과를 재사용한다. 제품 구현은 추가 변경하지 않고 버전 메타데이터를 1.11.19로 갱신한다.

헤더 클릭 처리 경로의 정렬, 파일·폴더 좌우 경로 Enter 후 현재 탭 유지, 최근 경로 선택·중복 제거·30개 제한·파일/폴더 분리·설정 파일 직렬화/복원·이전 설정 호환성을 확인했다. WPF 경로 입력창의 렌더링 이미지를 확인했다. IME 조합 이벤트는 합성 이벤트로 검사했으며 실제 한국어 IME와 여러 OS 화면 배율은 개발자가 수동 검증하지 않았다. 전자처럼 넓게 입력되는 현상은 사용자가 자신의 환경에서 Alt + =에 의한 문자 폭 모드 전환임을 확인했고 같은 키로 정상 복귀했다.

배포 시 자체 포함 EXE 파일 버전, ZIP 내부 EXE 및 고정 경로 EXE의 SHA-256, GitHub 첨부 크기·SHA-256과 공개 latest를 확인한다. 완료한 실행 테스트와 최종 단일 EXE의 별도 실행은 반복하지 않는다. 사용자 `.gitignore` 변경은 보존하고 커밋에서 제외한다.

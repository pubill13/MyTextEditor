# v1.11.18 배포 확인

구현 단계에서 완료한 검증 결과를 재사용했다. 자세한 수치와 범위는 [폴더 비교 검증 기록](../folder-compare-progress-2026-11-12.md)에 있다.

- Release 솔루션 빌드: 경고 0개·오류 0개.
- Core 44/44, 폴더 비교·입력 UI 회귀 통과.
- 폴더 우선 자연 정렬, 양쪽 날짜·형식·크기·상태 양방향 정렬, 누락 값·선택·필터·새로고침 유지, 취소·폴더 접근 실패 시 이전 결과 보존 검증 통과.
- 빈 파일 5만 쌍 수정 전후 각각 3회 검사: 중앙값 28.16초 → 2.76초. 작은 파일 1,000쌍 및 64MiB 파일 4쌍 내용 비교 통과.
- 밝은/어두운 테마, 로딩 중, 최소 너비 화면 확인. 실제 DPI 전환 검사는 하지 않았다.

배포 단계에서는 버전만 1.11.18로 갱신하고 Windows x64 자체 포함 단일 EXE를 게시 빌드했다. 최초 샌드박스 내 NuGet 복원은 네트워크 권한 오류로 실패했으며, 권한을 확보한 재실행에서 복원·게시 빌드가 성공했다. 최종 EXE 파일 버전은 1.11.18.0이며, ZIP 내부 EXE의 SHA-256이 원본과 일치한다. 두 배포 파일의 크기·해시는 `package.json`에 기록했다. 최종 배포 EXE를 별도 실행하거나 완료한 동작 테스트를 반복하지 않았다.

사용자 `.gitignore` 변경은 커밋에 포함하지 않는다. 기존 사용자 창과 수동 폴더 비교 테스트 창을 종료하거나 설치된 EXE를 교체하지 않는다. GitHub 공개 상태·최신 태그·서버 첨부 파일 해시 검증 결과는 `publication.json`에 기록한다.

# OmniEdit v1.11.18

## 개선 사항

- 파일 정보를 반복 조회하는 비용을 줄이고 최대 4개 파일을 동시에 비교하여 대량 폴더 비교를 개선했습니다. 같은 크기·수정 날짜라도 실제 파일 내용을 바이트 단위로 비교합니다.
- 목록 수집과 비교 진행 막대, 처리 개수·퍼센트·현재 파일의 읽은 용량을 표시합니다. 취소하거나 폴더를 읽지 못하면 이전 결과를 유지합니다.
- 양쪽 목록에 수정 날짜·확장자 기반 파일 형식·B/KB/MB 크기를 표시합니다. 정확한 바이트 수는 행 툴팁으로 확인할 수 있습니다.
- 폴더를 먼저 모으고 이름 안의 숫자를 자연스럽게 정렬합니다(파일2 → 파일10). 이름·날짜·형식·크기·상태 열 제목을 누르면 정렬 방향이 바뀌며, 날짜·크기는 클릭한 쪽을 기준으로 정렬합니다. 좌우 대응 행과 탭별 정렬 설정은 유지합니다.
- 현재 폴더만 비교하며 하위 폴더는 더블클릭/Enter로 새 탭에서 비교하는 기존 동작을 유지합니다.

## 성능과 검증

- 로컬 빈 파일 50,000쌍 검사 3회 중앙값: 28.16초 → 2.76초, 약 90% 단축. 파일 생성 시간은 제외했으며 환경·파일 내용에 따라 결과는 달라집니다.
- Release 빌드 0경고/0오류, Core 44/44, 폴더 비교·입력 UI 회귀, 정렬·필터·취소·접근 실패·새로고침 검증을 통과했습니다.
- 작은 파일 1,000쌍 및 64MiB 파일 4쌍 비교와 밝은/어두운 테마·최소 너비 화면 검증을 통과했습니다. 실제 DPI 전환 검사는 포함하지 않았습니다.

## 설치

- Windows x64 자체 포함 실행 파일로 .NET을 별도로 설치할 필요가 없습니다. `OmniEdit.exe`를 받거나 ZIP을 풀어 실행하세요.
- 실행 파일 교체 전 기존 메인 창과 비교·병합 창을 모두 종료하세요. 설정과 매크로 저장 위치는 기존 `%LOCALAPPDATA%\MyTextEditor`를 유지합니다.
